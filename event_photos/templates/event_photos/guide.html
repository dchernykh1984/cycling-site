{% trans "How to prepare a photo album for the site" %}

{% trans "The site shows photos from a Dropbox folder shared as 'Anyone with the link can view'. The photos lie at the top of the folder, next to a file photo-index.v1.json that says which bibs are on which photo." %}

{% trans "Steps" %}

  1. {% blocktrans with url=indexer_url %}Download Sport Photo Indexer for your computer and open the album folder in it.{% endblocktrans %}
  2. {% trans "Type the bibs on each photo and press Enter: the index is saved after every photo, so you can stop and come back." %}
  3. {% trans "In Dropbox, share the folder: 'Anyone with the link can view', and copy the link." %}
  4. {% trans "On the event page open 'Manage event photos', paste the link and press 'Add and import'." %}
  5. {% trans "After indexing more photos, press 'Refresh participants' tagging' there." %}

{% blocktrans with url=indexer_project_url %}Instead of steps 1 and 2, the folder can be indexed with the skill in the Sport Photo Indexer project.{% endblocktrans %}

{% trans "Limits" %}

  • {% blocktrans %}One album: at most {{ max_photos }} photos, {{ max_bibs }} bibs on a photo, and an index file of at most {{ max_mb }} MB.{% endblocktrans %}
  • {% trans "Only the photos at the top of the folder are shown; subfolders are not read." %}
  • {% trans "Dropbox cannot make a thumbnail of a photo over 20 MB; the indexer makes a small preview for such photos." %}
  • {% trans "Dropbox limits the traffic of shared links (1 TB a day on paid plans, 20 GB on Basic). Over it, all the owner's shared links pause for a day." %}

{% trans "If something goes wrong" %}

{% trans "When an import fails, the event's photo page names the field of the index and what is wrong with it, and the last good version stays on the site. Fix it in the indexer and refresh." %}
