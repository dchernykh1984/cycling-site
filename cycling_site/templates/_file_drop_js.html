{% comment %}A file dragged onto a field instead of picked by its button, on a computer: a phone has nothing to drag. window.fileDrop(zone, take) marks the zone while a file is over it and hands take() the files let go there; window.fileDropInto(input, zone) puts them into the input as though they had been picked. A file let go anywhere else on the page is not opened in its place, which would lose what was typed. Defined once however many times a page includes it.{% endcomment %}
