{% comment %} Generic multi-select cascade factory shared by the location, direction/discipline and event-type filters (issue #108). window.MultiSelectCascade(config) wires a set of Bootstrap dropdown menus (one per cascade level) of checkboxes with a master "All" checkbox; each lower level merges the children of every selected parent and de-duplicates them by name (same name => one checkbox whose value carries all ids, so a stored selection stays order-stable across re-renders). config: levels: [{btn: HTMLElement, menu: HTMLElement}, ...] // index 0 == depth 1 nodesUnder(depth, parentPks): [{pk, name}, ...] // children for the selected parents restoreChains(): [[{depth, pk}, ...], ...] // ancestor chains to pre-select labels: {all: "...", selected: "..."} onChange(): called after every user-driven selection change returns {effective(), effectivePks(), effectiveDepth(), refresh()}. {% endcomment %}
